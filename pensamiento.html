Antes de empezar

Reglas de oro del examen

Revisalas siempre, antes de empezar y antes de entregar.

Prohibido
  • El operador in para buscar (if x in lista), .index(), .sort(), sorted() y cualquier búsqueda u ordenamiento nativo de Python.
Lo que sí se pide
  • Búsquedas: recorriendo con índices, for i in range(len(...)).
  • Ordenamientos: a mano, con los algoritmos vistos (burbuja, inserción, selección).
  • Se valora modularizar con funciones y la claridad.
  • Antes de entregar: releé la consigna y verificá que no usaste nada prohibido.

El in de for x in lista: es sintaxis del bucle y no es el operador de pertenencia; lo que se evita es preguntar x in lista en una condición. Para no dudar, recorré con range(len(...)).

Practicá esto: en el laboratorio, los ejercicios con «Reglas de oro» revisan tu código y te dicen qué prohibido usaste. Modularizar: sin repetidos

Bucles

while: no sé cuántas veces

Menús, validaciones. Necesita variable de control + condición + actualización; si falta la actualización, el bucle es infinito.

while opcion != 0:      # bandera
    opcion = int(input("Opción: "))

for + range: cantidad conocida

range(5)         # 0,1,2,3,4
range(2, 6)      # 2,3,4,5  (NO incluye el 6)
range(0, 10, 2)  # 0,2,4,6,8

Con paso negativo se recorre al revés: range(4, 0, -1) da 4, 3, 2, 1.

AnidadosSon la base de las matrices. Si el externo repite n veces y el interno m, el cuerpo corre n × m veces.

Listas (vectores)

Recorrido con índice y operaciones a mano:

for i in range(len(numeros)):
    suma += numeros[i]              # suma

mayor = numeros[0]
for i in range(len(numeros)):
    if numeros[i] > mayor:          # máximo
        mayor = numeros[i]

El máximo arranca en numeros[0], no en 0: con una lista de negativos el 0 «ganaría» sin estar en la lista.

Inmutables, ideales para devolver varios valores: return (fila, columna) y se recibe con f, c = funcion().

Diccionarios

alumno["nombre"] accede; alumno["clave"] = valor agrega o modifica. Para contar sin in: cuentas[v] = cuentas.get(v, 0) + 1.

Matrices

Lista de listas. Recorrido completo:

for i in range(len(matriz)):
    for j in range(len(matriz[i])):
        print(matriz[i][j])

Diagonal principal: matriz[i][i]. Crear una vacía: doble for con fila.append(0).

Clave del examenUsá siempre len(matriz) y len(matriz[i]), nunca números fijos como range(3). Así el código sirve para cualquier tamaño.

Fundamentos · 5

Funciones y entry point

def area(base, altura):        # CON retorno: devuelve un resultado
    return base * altura

def mostrar(matriz):           # SIN retorno: solo hace una acción
    for fila in matriz:
        print(fila)
  • Parámetro = nombre en la definición. Argumento = valor al invocar.
  • Con retorno cuando necesitás el resultado para seguir (x = area(4, 5)). Sin retorno cuando solo ejecuta (mostrar, imprimir el menú).
  • Las listas y matrices se pasan por referencia: si las modificás adentro, cambian afuera (por eso los ordenamientos «en el lugar» no necesitan devolver nada).

Entry point: el «guardián» del programa

if __name__ == "__main__":
    main()

Si ejecutás el archivo directo, __name__ vale "__main__" y corre main(). Si lo importás desde otro archivo, no corre main(), pero sí podés usar sus funciones.

Algoritmos · 6

Búsqueda

Secuencial · O(n)

Recorre uno por uno. No necesita orden.

def busqueda_secuencial(lista, valor):
    for i in range(len(lista)):
        if lista[i] == valor:
            return i
    return -1

Binaria · O(log n)

Descarta mitades. Requiere lista ordenada.

def busqueda_binaria(lista, valor):
    izquierda = 0
    derecha = len(lista) - 1
    while izquierda <= derecha:
        medio = (izquierda + derecha) // 2
        if lista[medio] == valor:
            return medio
        elif lista[medio] < valor:
            izquierda = medio + 1   # a la derecha
        else:
            derecha = medio - 1     # a la izquierda
    return -1

Algoritmos · 7

Ordenamiento

Tres algoritmos, siempre escritos a mano. Mismo ejemplo para los tres: [5, 3, 8, 1] de menor a mayor.

Burbuja: compara vecinos j y j+1 y los intercambia

n = len(lista)
for i in range(n):
    for j in range(0, n - i - 1):
        if lista[j] > lista[j + 1]:     # con < = mayor a menor
            aux = lista[j]
            lista[j] = lista[j + 1]
            lista[j + 1] = aux
vuelta 1: [5,3,8,1] → [3,5,8,1] → (5,8 no) → [3,5,1,8] · el mayor «burbujeó» al final
vuelta 2: [3,5,1,8] → (3,5 no) → [3,1,5,8] · …y así hasta que no hay cambios

Inserción: for + while, inserta cada «carta» en su lugar

for i in range(1, len(lista)):          # arranca en 1
    actual = lista[i]
    j = i - 1
    while j >= 0 and lista[j] > actual:
        lista[j + 1] = lista[j]
        j -= 1
    lista[j + 1] = actual
i=1: actual=3 → desplaza el 5 → [3,5,8,1]
i=2: actual=8 → no desplaza nada → [3,5,8,1]
i=3: actual=1 → desplaza 8, 5 y 3 → [1,3,5,8]

Selección: for + for, busca el menor y hace un solo intercambio

n = len(lista)
for i in range(n):
    menor = i
    for j in range(i + 1, n):
        if lista[j] < lista[menor]:
            menor = j
    aux = lista[i]
    lista[i] = lista[menor]
    lista[menor] = aux
i=0: el menor del resto es el 1 (posición 3) → intercambia → [1,3,8,5]
i=1: el menor del resto ya está en su lugar → [1,3,8,5]
i=2: el menor del resto es el 5 → intercambia → [1,3,5,8]

Cómo reconocer cada algoritmo (opción múltiple)

Si ves…Es…
lista[j] > lista[j+1] (compara vecinos)Burbuja
actual = lista[i] + un while que desplazaInserción
menor = i + for interno que guarda el menorSelección
recorre lista[i] comparando con un valor buscadoBúsqueda secuencial
medio, izquierda, derecha, while izq <= derBúsqueda binaria

Examen · 8

Trampas típicas

Donde se pierden puntos. Cada una tiene su ejercicio de «encontrá el error» en el laboratorio.

TrampaQué pasaEjercicio
len() vs len() - 1Como índice directo (derecha = len(lista) - 1) va con -1; en range(len(...)) no, porque range ya excluye el tope.E3
Inserción: el rango del forVa range(1, len(lista)). Con range(len(lista) - 1) te saltás el último (bug clásico del simulacro).E1
Binaria con ramas invertidasSi lista[medio] < valor → izquierda = medio + 1 (¡no derecha!).E2
Orden ascendente vs descendenteBurbuja con > ordena de menor a mayor; con <, de mayor a menor. Releé qué piden.E4
Piso e índiceEl usuario piensa «piso 1» pero la matriz indexa desde 0: mostrá i + 1 y restá 1 al leer (matriz[piso - 1]).E9
Validar entradasChequeá rangos (if piso >= 1 and piso <= 5) para no reventar con IndexError.E9 M8
Tipo de datoSi la consigna dice float (por ejemplo consumos), usá float(input(...)), no int.E10
Máximo que arranca en 0Con negativos devuelve un 0 que no está en la lista. Arrancá con el primer elemento.E5
Acumulador mal ubicadoInicializar suma = 0 dentro del for la reinicia en cada vuelta.E6
Números fijos en matricesrange(3) sirve solo para 3×3. Usá len().E7

Examen · 9

Estructura de un programa con menú

El patrón del examen: cubre de una tres requisitos que suelen pedir (menú con bandera, función con retorno y función sin retorno).

def main():
    datos = cargar()                 # o matriz de prueba
    opcion = -1
    while opcion != 0:               # bucle controlado por bandera
        print("1. ...   2. ...   0. Salir")
        opcion = int(input("Opción: "))
        if opcion == 1:
            mostrar(datos)           # función SIN retorno
        elif opcion == 2:
            r = calcular(datos)      # función CON retorno
            print(r)
        elif opcion == 0:
            print("Saliendo...")
        else:
            print("Opción inválida")

if __name__ == "__main__":
    main()
Checklist antes de entregar
  • ¿Usé in, .index(), .sort() o sorted()? Si sí, rehacerlo a mano.
  • ¿Mis recorridos usan len() en vez de números fijos?
  • ¿Cada función hace una sola cosa y tiene el retorno que corresponde?
  • ¿Validé las entradas y el tipo (int / float) que pide la consigna?
